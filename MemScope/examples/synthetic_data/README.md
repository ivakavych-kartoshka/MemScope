# Synthetic example data

The runnable scenario is generated deterministically by `memscope.data.synthetic`.
It represents fictional calendar, health, shopping, and travel records. No record
comes from LoCoMo, LongMemEval, Memora, PA-Bench, ProfileFoundry, PersonaChat, a
phone, or a real person.

Any output derived from this directory must retain the label:

> synthetic smoke-test output, not a paper result
